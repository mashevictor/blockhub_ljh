# 检验危急值报告与处置路径（示范）

## 一、概述

检验危急值（Critical Value）是指检验结果极度异常，提示患者可能处于生命危险状态，需立即采取临床干预的数值。本知识库示范文档基于通用危急值管理原则，梳理报告、接收、处置及闭环流程，旨在提升医疗安全与响应效率。

## 二、危急值定义示例

各医疗机构应根据本院服务范围、检验项目及参考范围制定危急值清单。以下为通用示例（非完整清单）：

| 检验项目 | 危急值低限 | 危急值高限 |
|----------|------------|------------|
| 血钾 | < 2.5 mmol/L | > 6.5 mmol/L |
| 血钠 | < 120 mmol/L | > 160 mmol/L |
| 血糖 | < 2.2 mmol/L | > 25.0 mmol/L |
| 血小板计数 | < 30 × 10^9/L | > 1000 × 10^9/L |
| 凝血酶原时间（PT） | — | > 30 秒 |
| 活化部分凝血活酶时间（APTT） | — | > 70 秒 |
| 血气pH | < 7.20 | > 7.60 |
| 肌钙蛋白I | — | 高于参考上限2倍 |

> **示范摘要**：上述数值仅作示例，实际危急值阈值需经医院临床与检验专家共识确定，并定期评审更新。

## 三、报告时限与通知闭环

### 3.1 报告时限
- 检验科在审核确认危急值后，应在 **5分钟内** 完成首次报告通知。
- 若首次通知未成功（如电话无人接听），应在 **10分钟内** 启动升级报告流程（如联系科室主任、总值班）。

### 3.2 通知闭环流程
1. **检验科发出**：通过LIS系统自动触发，同时以电话或即时通讯工具通知目标科室（如病区护士站、急诊分诊台）。
2. **接收确认**：接收人（护士或医生）需在 **5分钟内** 在系统中点击“接收”或通过电话复述确认。
3. **记录要素**：报告时间、接收人姓名、患者ID、危急值项目及数值、通知方式。
4. **升级机制**：若首次通知后 **15分钟** 内未收到临床处置反馈，系统自动向科室主任及医务处推送待办。

## 四、复核与记录

### 4.1 复核要求
- 检验科应对危急值结果进行 **双人复核**（检验技师+审核人员），确保结果准确无误。
- 若结果与临床不符（如标本溶血、采集错误），需在记录中注明并重新采样。

### 4.2 记录字段
| 字段 | 说明 |
|------|------|
| 患者基本信息 | 姓名、住院号/门诊号、科室、床号 |
| 危急值项目 | 如“血钾” |
| 危急值结果 | 数值及单位 |
| 报告时间 | 精确到分钟 |
| 通知方式 | 电话/系统弹窗/即时通讯 |
| 接收人 | 姓名及工号 |
| 复核人 | 检验科双人签名 |
| 临床处置 | 医生下达的医嘱（如补钾、透析） |
| 处置时间 | 精确到分钟 |
| 闭环状态 | 已接收/已处置/已反馈 |

## 五、与信息系统联动

### 5.1 待办任务推送
- **LIS系统**：检验科审核后，自动向对应科室的护士站电脑、医生工作站推送待办弹窗，显示“危急值待处理”。
- **移动端**：通过医院APP或企业微信向值班医生、护士推送消息，点击可查看详情。
- **升级提醒**：若超时未响应，系统向科室主任、医务处、护理部发送短信或语音电话。

### 5.2 闭环监控
- 医务处可通过管理驾驶舱实时查看全院危急值报告及时率、处置及时率、闭环率。
- 每月生成报表，纳入科室质量考核指标。

## 六、常见误区

1. **通知对象错误**：仅通知护士而未通知医生，导致处置延迟。正确做法：护士接收后应立即通知主管医生。
2. **记录不完整**：遗漏处置时间或反馈结果，导致无法追溯。应确保所有字段填写完整。
3. **复核流于形式**：单人复核或未核对标本质量。必须双人复核，并确认标本合格。
4. **系统待办忽略**：医生或护士未及时查看系统弹窗，依赖电话通知。应养成定期查看待办的习惯。
5. **升级机制未启用**：超时未处置时未启动升级流程。系统应自动触发，人工也应主动上报。

## 七、适用场景

- 住院病区、急诊科、ICU、手术室等临床科室。
- 检验科、输血科、病理科等辅助科室。
- 医务处、护理部、质控科等管理部门。

## 八、操作要点

1. **检验科**：审核后立即报告，双人复核，记录完整。
2. **护士**：接收后5分钟内通知医生，并在系统中确认。
3. **医生**：收到通知后15分钟内下达处置医嘱，并在系统中反馈。
4. **管理部门**：定期抽查闭环情况，分析超时原因并改进。
