# 临床路径与 MDT 多学科协作要点（示范）

## 一、概述

临床路径（Clinical Pathway）与多学科协作（Multidisciplinary Team, MDT）是现代医院精细化管理和整合医疗的核心工具。本知识库旨在规范路径的纳入/退出标准、变异记录流程，以及MDT会诊的申请要素、结论归档与随访要求，提升诊疗同质化与协作效率。

## 二、临床路径管理要点

### 2.1 路径纳入标准
- 疾病诊断明确，且符合医院发布的路径病种清单（如社区获得性肺炎、剖宫产、髋关节置换等）。
- 患者无严重合并症或并发症，预期可按照路径完成主要诊疗环节。
- 患者或家属知情同意，并签署路径知情文件。

### 2.2 路径退出标准
- 出现严重并发症或病情恶化，需转入ICU或更改主要治疗方案。
- 诊断变更，不再符合路径病种。
- 患者或家属强烈要求退出，并签署退出记录。
- 住院时间超过路径上限的150%，且无合理理由。

### 2.3 变异记录要求
- **定义**：任何偏离路径预定步骤、检查、用药或住院天数的行为。
- **记录字段**：变异发生时间、变异内容（如检查未执行、药物调整）、变异原因（患者因素、医疗因素、系统因素）、处理措施、责任人。
- **信息系统联动**：在HIS或路径系统中设置变异标记，自动触发提醒，并汇总至科室质控报表。

### 2.4 路径评估与改进
- 每月统计路径完成率、变异率、平均住院日、费用等指标。
- 每季度组织路径管理小组讨论高频变异，修订路径文本。

## 三、MDT 多学科协作要点

### 3.1 MDT 会诊申请要素
- **申请科室**：填写科室名称、主治医师、患者基本信息（住院号、床号）。
- **会诊目的**：明确需要解决的问题（如诊断困难、治疗方案选择、术前评估）。
- **参与科室**：根据病情邀请相关科室（如肿瘤科、影像科、病理科、营养科、药学等）。
- **资料准备**：上传病历摘要、关键检查结果（影像、病理、检验）。
- **时间与地点**：建议固定时间（如每周三下午），地点为MDT会议室或线上平台。

### 3.2 MDT 讨论流程
1. 主管医师汇报病史（5分钟）。
2. 影像科、病理科等解读辅助检查（5分钟）。
3. 各专科依次发表意见（每人3-5分钟）。
4. 主持人（通常为科室主任或资深专家）总结形成统一意见。

### 3.3 结论归档与随访
- **归档内容**：MDT结论（诊断、分期、治疗建议、随访计划）、参与人员签名、讨论时间。
- **归档位置**：电子病历系统MDT模块或会诊记录页。
- **随访要求**：
  - 主管医师在24小时内将结论告知患者及家属。
  - 按MDT建议调整治疗方案，并在病程中记录。
  - 随访节点：出院后1个月、3个月、6个月（根据病种调整）。
  - 随访方式：门诊复诊、电话或互联网医院平台。

## 四、常见误区

| 误区 | 正确做法 |
|------|----------|
| 路径一旦纳入不可退出 | 出现退出标准应及时退出，并记录原因 |
| 变异记录流于形式 | 变异是改进路径的重要依据，应真实、完整记录 |
| MDT 会诊只针对疑难病例 | 也适用于常规肿瘤、慢性病综合管理 |
| MDT 结论不归档 | 必须归档至病历，作为法律依据和质控凭证 |
| 随访仅由护士完成 | 主管医师应主导随访，护士协助 |

## 五、与信息系统联动

- **临床路径系统**：自动监测路径执行节点，预警变异和超时。
- **MDT 平台**：支持线上申请、资料共享、讨论记录、结论归档。
- **随访系统**：自动生成随访任务，提醒医师和患者。

## 六、适用场景

- 肿瘤多学科诊疗（如肺癌、乳腺癌、结直肠癌）。
- 复杂创伤、急危重症综合救治。
- 慢性病全程管理（如糖尿病、慢性肾病）。
- 手术科室围术期管理（如关节置换、冠脉搭桥）。

## 七、操作要点总结

1. **路径管理**：严格把握纳入/退出标准，及时记录变异。
2. **MDT 协作**：申请要素齐全，讨论高效，结论明确。
3. **归档与随访**：结论归档至病历，按计划随访并记录。
4. **持续改进**：定期分析数据，优化路径和MDT流程。
