# 急诊分诊 ESI 分级要点（示范）

## 一、ESI 分级概述

急诊严重度指数（Emergency Severity Index, ESI）是国际通用的急诊分诊工具，将患者分为 1～5 级，级别越高病情越轻。分诊护士需在 2～5 分钟内完成评估，核心依据为：**病情稳定性**、**生命体征**、**资源需求**。

## 二、ESI 1～5 级判定要点

### 1. ESI 1 级（濒危）
- **定义**：即刻生命威胁，需立即抢救。
- **红旗症状**：
  - 呼吸暂停/严重呼吸困难（SpO₂ < 90% 且吸氧不改善）
  - 无脉/严重心律失常（如室颤、心脏停搏）
  - 意识丧失（GCS ≤ 8）或持续惊厥
  - 严重创伤（大出血、气道受阻）
- **操作要点**：立即送入抢救室，启动急救团队，无需等待分诊记录完成。

### 2. ESI 2 级（危重）
- **定义**：高危状态，需快速干预。
- **红旗症状**：
  - 胸痛伴大汗、呼吸困难（疑似急性冠脉综合征）
  - 呼吸困难（SpO₂ < 90% 但吸氧可改善）
  - 意识改变（GCS 9～12）或急性精神异常
  - 剧烈疼痛（NRS ≥ 7）
  - 高热（体温 > 41°C）伴休克表现
- **操作要点**：安排优先就诊，10 分钟内完成评估与初步处理。

### 3. ESI 3 级（紧急）
- **定义**：病情稳定但需多项资源（≥ 2 项）。
- **常见场景**：
  - 腹痛待查（需血常规、超声）
  - 骨折（需 X 线、石膏固定）
  - 轻度呼吸困难（需吸氧、胸片）
- **资源需求清单**（示范）：
  - 实验室检查（血、尿）
  - 影像学（X 线、CT、超声）
  - 静脉输液/药物
  - 专科会诊
- **操作要点**：30 分钟内安排就诊，动态监测生命体征。

### 4. ESI 4 级（次紧急）
- **定义**：病情稳定，仅需 1 项资源。
- **常见场景**：
  - 单纯外伤（清创缝合）
  - 轻度感染（开具口服药）
  - 慢性病复诊（仅需开药）
- **操作要点**：可等待 1～2 小时，指导患者候诊。

### 5. ESI 5 级（非紧急）
- **定义**：病情稳定，无需资源。
- **常见场景**：
  - 轻微擦伤（仅需消毒）
  - 慢性病咨询（无需检查）
  - 开具病假条
- **操作要点**：可转至门诊或社区，候诊时间 > 2 小时。

## 三、分诊记录字段（示范）

| 字段名称 | 内容要求 | 示例 |
|----------|----------|------|
| 主诉 | 患者自述，简明扼要 | “胸痛 2 小时” |
| 生命体征 | 体温、脉搏、呼吸、血压、SpO₂ | T 36.5°C, P 88, R 20, BP 130/80, SpO₂ 97% |
| 红旗症状 | 勾选存在项 | 胸痛、大汗 |
| ESI 级别 | 1～5 级 | 2 级 |
| 资源需求 | 勾选所需资源 | 心电图、心肌酶、吸氧 |
| 分诊时间 | 精确到分钟 | 2025-03-15 14:30 |
| 护士签名 | 电子签名 | 张三 |

## 四、与预问诊系统衔接注意点

1. **数据同步**：预问诊系统（如自助机、手机端）采集的主诉、过敏史、既往史应自动导入分诊记录，减少重复录入。
2. **预警提示**：当预问诊系统识别到红旗症状（如“胸痛”“呼吸困难”）时，自动触发分诊护士终端提醒，优先处理。
3. **资源预判**：基于预问诊信息，系统可初步推荐 ESI 级别（如“胸痛+年龄>60”提示 ESI 2），但最终由护士确认。
4. **信息完整性**：预问诊系统需强制采集关键字段（如疼痛评分、过敏药物），否则无法提交，确保分诊记录完整。
5. **隐私保护**：预问诊数据传输需加密，患者身份信息脱敏显示。

## 五、常见误区

1. **过度依赖系统**：ESI 分级需结合临床判断，不可完全依赖自动推荐。例如，预问诊系统可能漏报“濒死感”。
2. **忽略动态变化**：患者候诊期间病情可能恶化，需定期复评（如 ESI 3 级每 30 分钟）。
3. **资源需求误判**：将“静脉输液”视为 1 项资源，但若同时需要“抽血”和“输液”，则为 2 项资源，应归为 ESI 3。
4. **生命体征测量不规范**：如未测量 SpO₂ 即判定呼吸正常，可能导致 ESI 级别偏低。

## 六、适用场景

- 综合医院急诊科分诊台
- 急诊护理培训与考核
- 分诊质量持续改进（如回顾性分析 ESI 级别与预后的符合率）

## 七、操作要点总结

1. **快速评估**：2 分钟内完成初步分级，危重患者立即处理。
2. **标准问询**：使用结构化问句（如“您哪里不舒服？什么时候开始的？疼痛评分？”）。
3. **团队协作**：分诊护士与抢救室、医生保持沟通，确保信息传递无误。
4. **记录规范**：电子记录实时保存，支持后续统计与审计。
