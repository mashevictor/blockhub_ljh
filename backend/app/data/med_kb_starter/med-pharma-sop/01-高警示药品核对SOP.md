# 高警示药品核对与给药 SOP（示范）

> **合规提示**：本文为医院信息管理 / 护理与药学知识库**示范文档**，仅供培训与系统检索演示。不构成诊疗建议，不替代执业医师、药师或护士的专业判断与书面制度。

## 一、适用场景

本 SOP 适用于全院各临床科室（含 ICU、急诊、手术室）对高警示药品（High-Alert Medications）的核对与给药操作。高警示药品指若使用错误或不当，可能对患者造成严重伤害甚至死亡的药品，包括但不限于：

- 静脉用抗心律失常药（如胺碘酮）
- 抗凝血药（如肝素、华法林）
- 高浓度电解质（如 10% 氯化钾、25% 硫酸镁）
- 胰岛素（特别是 U-500 浓度）
- 化疗药物
- 麻醉药与肌松药

## 二、高警示药品清单管理原则

### 2.1 清单制定与更新

- 由药事管理与药物治疗学委员会（示范）每年审核并发布《高警示药品目录》。
- 各科室根据专业特点建立科级补充清单，报医务处备案。
- 新药引进或药品规格变更时，药学部门应在 7 个工作日内更新清单并通知临床。

### 2.2 标识与存放

- 高警示药品存放区域设置统一红色警示标识（示范：黄底红字“高警示药品”）。
- 原则上单独存放，不得与普通药品混放；若条件限制，需在药盒/抽屉上明确标注。
- 高浓度电解质（如 10% KCl）必须单独加锁管理。

## 三、双人核对制度

### 3.1 核对时机

- 药品从药房领出时（药房发药人与科室接收人双签）。
- 给药前准备时（一名护士配药，另一名护士核对）。
- 给药时（给药护士与另一名护士或医师共同确认）。

### 3.2 核对内容（“五对”扩展为“七对”）

| 项目 | 核对要点 |
|------|----------|
| 患者身份 | 至少两种方式（如姓名+住院号/出生日期） |
| 药品名称 | 通用名（商品名仅作参考），避免音似/形似混淆 |
| 剂量 | 核对计算过程（如按体重、体表面积） |
| 浓度 | 特别注意高浓度药品的稀释比例 |
| 给药途径 | 静脉、肌注、皮下等，确认与医嘱一致 |
| 给药时间 | 确认频次、滴速（如 mL/h） |
| 有效期 | 检查药品外观、有效期，异常立即停用 |

### 3.3 双人核对操作要点

- 核对时需“唱读”：一人读出药品信息，另一人复述并确认。
- 若其中一人为实习生或进修生，需由带教老师完成核对。
- 核对后双方在给药记录单上签名（电子签名或手签）。

## 四、给药前“五对”确认流程

给药前，护士必须独立完成以下五步确认（可结合信息系统）：

1. **患者身份**：扫描腕带条码，核对姓名、住院号。
2. **药品标签**：扫描药品条码，系统自动匹配医嘱。
3. **剂量计算**：若需计算（如肝素泵入剂量），使用院内统一计算器或公式表。
4. **给药途径**：确认注射器/输液器标签与途径一致（如“静脉输注”需用输液泵）。
5. **时间与速度**：设置输液泵参数后，双人复核泵速。

## 五、异常上报与处理

### 5.1 异常事件定义

- 药品错误（品种、剂量、途径、患者错误）
- 药品质量问题（变色、沉淀、包装破损）
- 给药设备故障（输液泵异常、注射器漏液）
- 患者出现严重不良反应（如过敏、低血压）

### 5.2 上报流程

1. **立即停止给药**，保留药品、输液器、注射器。
2. **评估患者**：监测生命体征，必要时启动急救。
3. **上报**：10 分钟内报告护士长及值班医师；24 小时内通过不良事件系统（示范：医院安全事件报告平台）提交详细报告。
4. **根本原因分析**：由护理部与医务处联合组织，每月汇总分析，制定改进措施。

## 六、与信息系统联动

### 6.1 医嘱系统提示

- 医师开具高警示药品时，系统弹出红色警示框，要求填写给药说明（如“稀释至 50 mL，泵速 5 mL/h”）。
- 系统自动计算最大单次剂量，超量时强制拦截。

### 6.2 护理执行系统

- 护士扫描患者腕带和药品条码后，系统自动核对并记录执行时间。
- 若未完成双人核对，系统禁止执行给药操作。
- 异常事件上报后，系统自动关联患者、药品、操作者信息。

### 6.3 数据监测

- 每月生成高警示药品使用分析报告（如使用频次、错误率、科室分布）。
- 对错误率高的科室进行专项培训。

## 七、常见误区

| 误区 | 正确做法 |
|------|----------|
| 双人核对只是形式，一人操作另一人签字 | 必须同时在场，逐项核对并唱读 |
| 高警示药品与普通药品可混放 | 必须分区存放，高浓度电解质加锁 |
| 信息系统提示可忽略 | 任何警示均需核实，不得直接跳过 |
| 异常事件上报后会被追责 | 医院实行非惩罚性上报，鼓励主动报告 |
| 给药前只核对药品名称即可 | 必须核对全部七项内容，缺一不可 |

## 八、培训与考核

- 新入职护士必须通过高警示药品知识考核（含模拟场景）。
- 每年至少一次全员培训，内容涵盖清单更新、典型案例分析。
- 科室每月自查，护理部每季度抽查，结果纳入绩效。
