# 医院感染：手卫生与隔离要点（示范）

## 一、适用场景

本文适用于以下场景的知识检索与培训：
- 临床医护人员手卫生依从性监测与改进
- 接触隔离与飞沫隔离措施的落实与督查
- 环境物表清洁消毒规范执行
- 职业暴露（血源性病原体）后紧急处理与报告流程

## 二、手卫生：WHO 五时刻与操作要点

### 2.1 WHO 手卫生五时刻（示范摘要）

根据世界卫生组织（WHO）《手卫生技术参考手册》，手卫生的五个关键时刻（Five Moments for Hand Hygiene）包括：

1. **接触患者前**：如握手、查体、测量生命体征前。
2. **清洁/无菌操作前**：如静脉穿刺、换药、导尿前。
3. **接触体液后**：如抽血、处理引流液、清理排泄物后。
4. **接触患者后**：如完成查体、护理操作后。
5. **接触患者周围环境后**：如接触床栏、床头柜、呼叫器后。

### 2.2 操作要点

- **洗手与手消毒选择**：
  - 当手部有可见污物或接触蛋白质类物质（如血液、体液）时，必须使用流动水+皂液洗手。
  - 无明显污物时，可使用含醇速干手消毒剂揉搓。
- **洗手步骤**：内、外、夹、弓、大、立、腕（七步洗手法），揉搓时间不少于15秒。
- **手消毒时机**：在两个连续的患者诊疗活动之间，若手部无明显污染，可使用速干手消毒剂。

### 2.3 常见误区

- 误区：戴手套可替代手卫生。
  - 纠正：戴手套前、脱手套后均需进行手卫生。手套可能破损或存在微小渗漏。
- 误区：速干手消毒剂对艰难梭菌、诺如病毒有效。
  - 纠正：酒精对艰难梭菌芽孢、诺如病毒效果有限，此类病原体感染或定植患者应使用流动水+皂液洗手。

## 三、隔离要点：接触隔离与飞沫隔离

### 3.1 接触隔离

适用于：多重耐药菌（如 MRSA、VRE、CRE）、艰难梭菌感染或定植患者。

| 要素 | 要求 |
|------|------|
| 单间隔离 | 优先单间，同种病原体可集中隔离 |
| 标识 | 门外悬挂蓝色“接触隔离”标识 |
| 个人防护装备（PPE） | 进入病室穿隔离衣、戴手套；离开时脱去并执行手卫生 |
| 专用物品 | 听诊器、血压计等专用；共用物品使用后立即清洁消毒 |
| 环境物表 | 每日至少清洁消毒2次，高频接触表面（床栏、门把手）加强消毒 |
| 医疗废物 | 双层黄色医疗废物袋，标注“接触隔离” |

### 3.2 飞沫隔离

适用于：流感、流行性脑脊髓膜炎、风疹等经飞沫传播的疾病。

| 要素 | 要求 |
|------|------|
| 单间隔离 | 优先单间，同种病原体可集中隔离；病室门保持关闭 |
| 标识 | 门外悬挂粉色“飞沫隔离”标识 |
| PPE | 进入病室佩戴医用外科口罩；近距离操作（<1米）加戴面屏 |
| 患者转运 | 患者佩戴外科口罩；限制外出 |
| 环境通风 | 自然通风或机械通风，换气次数≥6次/小时 |

### 3.3 常见误区

- 误区：飞沫隔离患者无需佩戴外科口罩。
  - 纠正：患者外出检查或转运时必须佩戴外科口罩，以减少飞沫扩散。
- 误区：接触隔离患者使用后的物品按普通医疗废物处理。
  - 纠正：应双层包装并明确标识，避免转运过程中污染环境。

## 四、环境物表清洁消毒

### 4.1 基本原则

- **分区管理**：清洁区、半污染区、污染区；不同区域使用不同颜色的抹布/拖把。
- **消毒剂选择**：
  - 含氯消毒剂（500mg/L 用于普通环境，1000-2000mg/L 用于血液/体液污染）。
  - 对艰难梭菌污染区域使用 1000-5000mg/L 含氯消毒剂。
- **频次**：每日至少2次；遇污染随时清洁消毒。

### 4.2 记录字段（信息系统联动）

建议在护理信息系统中记录以下字段：
- 执行时间、执行人、区域（如病房号、床号）
- 清洁消毒对象（如床栏、地面、卫生间）
- 消毒剂名称、浓度、作用时间
- 异常情况（如污染事件、消毒剂更换）

## 五、职业暴露报告与处理

### 5.1 暴露后紧急处理

1. **皮肤暴露**：立即用肥皂液和流动水清洗污染部位。
2. **黏膜暴露**：用生理盐水或清水反复冲洗。
3. **针刺伤**：由近心端向远心端挤压伤口，挤出血液，再用流动水冲洗，禁止局部按压。
4. **消毒**：75%酒精或0.5%碘伏消毒伤口。

### 5.2 报告流程

1. **立即报告**：通知科室负责人，填写《职业暴露登记表》。
2. **评估与检测**：医院感染管理科评估暴露级别，对暴露源（患者）进行 HBV、HCV、HIV、梅毒检测。
3. **预防用药**：根据评估结果，在暴露后4小时内启动预防用药（如乙肝免疫球蛋白、抗病毒药物）。
4. **随访**：暴露后0、1、3、6个月进行血清学检测。

### 5.3 记录字段（信息系统联动）

- 暴露时间、地点、暴露方式（针刺、割伤、喷溅等）
- 暴露源病原体检测结果
- 暴露者免疫状态（如乙肝抗体滴度）
- 处理措施（清洗、消毒、用药）
- 随访结果

## 六、与信息系统联动建议

- **手卫生监测**：通过电子感应器或扫码记录手卫生时机与执行情况，自动生成依从率报表。
- **隔离预警**：患者入院时诊断或微生物结果触发隔离医嘱，系统自动在电子病历和床头卡显示隔离类型。
- **环境清洁提醒**：系统根据隔离类型自动生成清洁消毒任务，并记录完成时间。
- **职业暴露管理**：暴露报告后自动触发评估、检测、用药提醒，并跟踪随访。

## 七、常见误区总结

| 误区 | 正确做法 |
|------|----------|
| 手卫生仅需在接触患者后执行 | 应遵循五时刻，包括接触前、无菌操作前等 |
| 戴手套可替代手卫生 | 戴前脱后均需手卫生 |
| 接触隔离患者物品按普通废物处理 | 双层黄色袋，标注隔离标识 |
| 飞沫隔离患者无需戴口罩 | 患者外出必须佩戴外科口罩 |
| 职业暴露后只需局部处理 | 必须报告并评估，必要时预防用药 |
