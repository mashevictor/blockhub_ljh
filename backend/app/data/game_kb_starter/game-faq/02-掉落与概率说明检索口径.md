> **合规提示**：本文为游戏运营 / 客服与内容合规知识库**示范文档**，仅供培训与系统检索演示。不替代官方公告、法务签发的版号材料或平台审核政策原文。

# 掉落与概率说明检索口径（示范）

## 一、适用场景

- **玩家咨询**：玩家询问“某道具掉率是多少”“抽卡概率是否真实”“保底如何计算”等。
- **争议处理**：玩家质疑概率不透明、实际掉落与公示不符。
- **内容审核**：运营发布概率公示公告前的内部审核。
- **合规自查**：定期检查游戏内概率说明是否符合平台与法规要求。

## 二、核心公示原则

### 1. 全面透明
- 所有涉及随机抽取（含抽卡、开箱、转盘、掉落）的道具，必须公示**所有可获取物品**的获取概率。
- 概率应以**百分比或千分比**形式呈现，避免模糊表述（如“较高”“稀有”）。

### 2. 稀有度分层
- 道具按稀有度分为若干层级（如 SSR/SR/R、传说/史诗/稀有），每层给出**综合概率**。
- 同一稀有度内若有多个道具，需注明**是否等概率**，若不等则需列出每个道具的单独概率。

### 3. 保底说明
- 若设有保底机制，必须明确：
  - 保底触发条件（如“每10次必出SR及以上”）。
  - 保底是否继承（跨卡池、跨活动）。
  - 保底计数重置规则（如“保底计数在获得当期UP角色后重置”）。

### 4. 概率公示位置
- 概率说明应置于**抽卡/购买界面**的明显位置，或通过“概率详情”按钮直达。
- 公告栏、官网、游戏内帮助中心应同步更新。

## 三、操作要点

### 客服应答口径

- **通用话术**：“您好，关于[道具名称]的获取概率，您可以在[抽卡界面/道具详情/官网公告]中查看详细公示。若您对概率有疑问，请提供截图，我们将为您核查。”
- **保底咨询**：“本卡池设有保底机制，每[次数]次抽取必得[稀有度]及以上道具。保底计数在[条件]下重置，具体请以游戏内概率公示为准。”

### 争议升级路径

1. **一线客服**：引导玩家查看公示，记录玩家反馈。
2. **二线运营**：若玩家坚持异议，调取该玩家抽卡日志，比对公示概率。
3. **法务/合规**：若涉及重大质疑，由法务出具概率验证报告，必要时配合监管调查。

## 四、记录字段

当处理概率相关投诉时，建议记录以下字段：

| 字段 | 说明 |
|------|------|
| 玩家ID | 匿名化处理 |
| 投诉时间 | 精确到秒 |
| 涉及道具 | 名称、稀有度、卡池 |
| 玩家声称 | 描述问题 |
| 实际抽卡记录 | 抽取次数、获得物品列表 |
| 公示概率 | 对应道具的官方公示概率 |
| 处理结果 | 是否异常、补偿措施 |

## 五、与信息系统联动

- **概率配置后台**：运营人员可在后台配置各卡池概率，系统自动生成公示文本。
- **抽卡日志系统**：记录每位玩家的每次抽取结果，支持按玩家ID、时间、卡池检索。
- **自动校验工具**：定期比对实际掉落统计与公示概率，偏差超过阈值时告警。
- **知识库对接**：客服系统自动关联概率说明文档，支持关键词检索（如“保底”“概率”“SSR”）。

## 六、常见误区

### 误区1：概率公示只针对付费抽卡
- **纠正**：所有随机获取机制（含免费掉落、活动兑换、任务奖励）均需公示概率。

### 误区2：保底机制可以模糊描述
- **纠正**：必须明确保底次数、保底内容、继承规则，避免“大概率”“可能”等措辞。

### 误区3：概率公示可以放在官网而不在游戏内
- **纠正**：游戏内必须提供直接入口，官网公示仅为补充。

### 误区4：概率可以随时调整而不通知
- **纠正**：概率调整需提前公告，并保留历史版本供玩家查阅。

## 七、示范摘要（引用通用原则）

> **《关于规范网络游戏运营加强事中事后监管工作的通知》**（示范摘要）：网络游戏运营企业应当及时在该游戏的官方网站或者随机抽取页面公示可能抽取或者合成的所有虚拟道具和增值服务的名称、性能、内容、数量及抽取或者合成概率。公示的随机抽取相关信息应当真实有效。

> **苹果App Store审核指南 3.1.1**（示范摘要）：App 如果提供随机虚拟物品抽取，则必须在玩家购买前明确告知每种物品的获取概率。

## 八、知识库检索字段建议

为便于客服与运营快速检索，建议为本文档配置以下标签：

- **标签**：概率公示、掉落、保底、随机抽取、合规、客服口径
- **适用岗位**：客服、运营、法务、QA
- **关联文档**：防沉迷说明、UGC审核规则、活动公告模板
- **更新频率**：每次概率调整或新卡池上线时更新
