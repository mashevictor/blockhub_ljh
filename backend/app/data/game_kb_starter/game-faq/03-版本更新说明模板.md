# 版本更新说明（Patch Notes）模板（示范）

## 一、适用场景

- **常规版本更新**：每周/双周例行更新，包含新功能、活动、平衡性调整。
- **紧急修复更新**：针对严重BUG或安全问题的热更新，需快速发布。
- **重大版本发布**：资料片、新职业、新系统上线，需配合预热与回滚预案。

## 二、文档结构（标准模板）

### 2.1 版本信息头

- **版本号**：如 v2.5.0
- **更新日期**：YYYY-MM-DD HH:MM（时区）
- **更新方式**：停服维护 / 不停服热更 / 资源预下载
- **预计时长**：如 2小时（若超时需触发补偿预案）

### 2.2 功能变更

- **新增内容**：
  - 新角色/新地图/新玩法（附简要说明）
  - 新活动（名称、时间、参与条件）
- **系统优化**：
  - UI/UX改进（如背包排序、组队匹配效率）
  - 性能优化（帧率、加载速度）
- **界面调整**：
  - 按钮位置、提示文字修改（需截图对比）

### 2.3 平衡性调整

- **角色/职业调整**：
  - 技能数值变更（如“烈焰斩”伤害从150%→130%）
  - 机制修改（如“无敌”持续时间缩短1秒）
- **装备/道具调整**：
  - 属性重平衡（如“传说之剑”攻击力+5%）
  - 掉落概率调整（需公示概率变化）
- **关卡/怪物调整**：
  - BOSS血量、技能频率修改
  - 关卡奖励调整（如经验值提升20%）

### 2.4 问题修复

- **严重BUG**：
  - 导致闪退、卡死、数据丢失的问题（如“组队时概率闪退”）
  - 影响公平性的漏洞（如“无限刷金币”）
- **一般BUG**：
  - 显示错误、文字错位、音效缺失
  - 特定机型兼容性问题
- **已知问题**：
  - 本次未修复但已定位的问题（如“部分玩家头像显示异常，下个版本修复”）
  - 临时规避方法（如“重启客户端可暂时解决”）

### 2.5 回档/补偿口径

- **回档触发条件**：
  - 更新导致数据异常（如玩家等级回退）
  - 紧急维护超过预定时间2倍
- **补偿标准**：
  - 停服补偿：每小时补偿100钻石+体力药水×1
  - 回档补偿：根据回档时长额外补偿（如24小时内登录奖励）
- **发放方式**：
  - 邮件自动发放，有效期7天
  - 需玩家手动领取（避免误领）

## 三、客服话术要点

### 3.1 通用话术

- **更新延迟**：
  > “亲爱的玩家，本次更新因技术调整预计延长30分钟，我们将额外发放补偿，感谢您的耐心等待。”
- **平衡性争议**：
  > “我们关注到部分玩家对XX调整的反馈，该调整基于全服数据平衡，后续将持续观察并优化。”

### 3.2 回档/补偿话术

- **回档通知**：
  > “由于更新异常，我们将对部分玩家进行数据回档至XX时间点，回档期间获得的道具将回收，并发放补偿。给您带来的不便深表歉意。”
- **补偿发放**：
  > “补偿已通过邮件发放，请及时领取。如有疑问请联系客服提供角色ID。”

### 3.3 争议处理

- **概率调整质疑**：
  > “本次调整已根据监管要求公示概率，具体数值可在游戏内‘概率说明’页面查看。”
- **技能削弱不满**：
  > “削弱是为了平衡PVP环境，我们会持续监控数据，必要时进行微调。”

## 四、操作要点

1. **版本发布前**：
   - 完成内部测试，确认无致命BUG
   - 准备回滚脚本与补偿方案
   - 同步客服团队更新内容与话术
2. **更新期间**：
   - 监控服务器状态，及时处理异常
   - 通过公告、社群实时通报进度
3. **更新后**：
   - 收集玩家反馈，重点关注平衡性、BUG
   - 48小时内发布热修复或后续计划

## 五、记录字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 版本号 | 唯一标识 | v2.5.0 |
| 更新类型 | 常规/紧急/重大 | 常规 |
| 影响范围 | 全服/部分服务器 | 全服 |
| 回档标记 | 是否触发回档 | 否 |
| 补偿方案 | 补偿内容与发放方式 | 钻石×200，邮件发放 |
| 客服工单数 | 更新后24小时相关工单 | 120 |

## 六、与信息系统联动

- **自动公告**：版本更新内容自动同步至游戏内公告栏、官网、社群机器人。
- **补偿发放**：通过运营后台设置补偿模板，一键发放至全服或指定玩家。
- **数据监控**：更新后自动对比关键指标（DAU、付费率、BUG上报率），异常时告警。

## 七、常见误区

1. **忽略已知问题**：未列出已知问题导致玩家重复反馈，增加客服压力。
2. **补偿不足**：停服时间过长但补偿标准过低，引发玩家不满。
3. **平衡性调整未公示**：未提前说明调整原因，导致玩家误解为“暗改”。
4. **回档范围不明确**：未说明回档影响的具体数据，造成玩家恐慌。
