# 敏感词与 UGC 审核口径（示范）

## 一、概述

本口径适用于游戏内 UGC（用户生成内容）的审核与处置，包括但不限于：角色名、公会名、聊天、签名、自定义头像、图片/视频投稿等。核心原则为“分级处置、人工复核、申诉闭环、全程留痕”。

## 二、分级处置机制

### 2.1 敏感词库分级

- **一级（绝对禁止）**：涉政、涉黄、涉暴、涉毒、涉赌等法律法规明确禁止的内容。
- **二级（限制发布）**：人身攻击、广告、诈骗信息、恶意引流等破坏社区秩序的内容。
- **三级（提醒过滤）**：轻度不文明用语、擦边球、易引发争议的表述。

### 2.2 处置动作

| 级别 | 系统自动处置 | 人工复核触发条件 |
|------|--------------|------------------|
| 一级 | 直接拦截，不发布 | 每次命中均触发人工复核（抽样或全量） |
| 二级 | 拦截并提示用户修改 | 同一用户连续命中≥3次/日，或累计≥10次/周 |
| 三级 | 替换为“***”并发布 | 用户申诉或系统标记异常（如高频发布） |

## 三、人工复核触发与流程

### 3.1 触发场景

- 系统自动拦截后，用户发起申诉。
- 系统根据风险模型（如新账号、异地登录、高频发布）标记的内容。
- 用户举报他人发布的疑似违规内容。
- 定期抽检（如每日随机抽取 0.1% 已发布内容）。

### 3.2 复核流程

1. **初审**：审核员依据敏感词库与审核标准，判断是否违规。
2. **复审**：若初审判定违规，且涉及一级敏感词或用户申诉，需由高级审核员复审。
3. **终审**：对争议内容或重大违规，提交法务/合规团队终审。

### 3.3 审核标准示例

- **上下文语境**：同一词汇在不同语境下可能不同，如“自残”在游戏攻略中可能为正常描述，在聊天中可能为违规。
- **变体识别**：谐音、拆字、拼音、emoji 组合等变体需纳入审核。
- **图片/视频**：OCR 识别文字 + 图像识别敏感元素（如裸露、暴力画面）。

## 四、申诉路径

### 4.1 用户申诉入口

- 游戏内：设置 → 客服 → 内容申诉。
- 官网/社区：申诉表单（需提供 UID、内容截图、申诉理由）。
- 客服热线/在线客服。

### 4.2 申诉处理时效

| 类型 | 处理时效 |
|------|----------|
| 自动拦截申诉 | 24 小时内 |
| 人工封禁申诉 | 48 小时内 |
| 账号处罚申诉 | 72 小时内 |

### 4.3 申诉结果反馈

- 通过：恢复内容/解除处罚，并推送通知。
- 驳回：说明具体违规原因，并提示再次申诉路径。

## 五、留痕字段与信息系统联动

### 5.1 必须留痕的字段

- **用户信息**：UID、角色名、IP、设备 ID、注册时间。
- **内容信息**：原始内容、发布时间、发布渠道（世界/公会/私聊等）。
- **审核信息**：审核员 ID、审核时间、处置动作（拦截/替换/通过）、复核记录。
- **申诉信息**：申诉时间、申诉理由、处理结果、处理人。

### 5.2 与内容风控系统联动

- **实时接口**：UGC 发布时，调用风控 API 进行敏感词匹配与模型评分。
- **异步队列**：图片/视频审核通过异步队列处理，结果回调。
- **数据同步**：审核记录实时写入日志系统，供后续审计与模型训练。
- **黑名单同步**：确认违规的用户 ID 自动加入黑名单，限制其发布权限。

## 六、常见误区

1. **过度依赖自动审核**：自动审核无法处理语境、变体、图片等复杂情况，必须结合人工复核。
2. **一刀切处置**：不同级别应区别对待，避免误伤正常用户。
3. **忽视申诉渠道**：申诉是用户权益保障，必须畅通且及时处理。
4. **留痕不完整**：缺乏关键字段会导致无法追溯，增加合规风险。
5. **未定期更新词库**：敏感词库需根据舆情、政策动态更新。
