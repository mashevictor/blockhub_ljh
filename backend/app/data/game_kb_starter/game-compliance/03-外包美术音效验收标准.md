# 外包美术/音效验收标准（示范）

## 一、适用场景

本验收标准适用于游戏研发过程中，由外部供应商（个人或公司）承接的**美术资源**（角色、场景、UI、特效等）与**音效资源**（背景音乐、音效、配音等）的交付与验收环节。

## 二、交付清单

### 2.1 美术资源

- **角色/怪物设计**：原画（含三视图）、模型（低模/高模）、贴图（漫反射、法线、高光等）、骨骼绑定文件、动作序列（含待机、移动、攻击等）。
- **场景资源**：概念图、模型、贴图、光照贴图、碰撞体数据。
- **UI资源**：界面设计稿、切图（含@2x/@3x）、图标、字体文件。
- **特效资源**：序列帧、粒子系统预设、材质球。
- **其他**：源文件（PSD、MAX、FBX、MA等）、导出文件（PNG、TGA、OGG等）、版本说明文档。

### 2.2 音效资源

- **背景音乐**：循环/非循环版本，时长≥30秒（循环类），采样率≥44.1kHz，位深≥16bit。
- **音效**：单次触发类（时长≤5秒）、循环类（时长≥10秒），格式WAV或OGG（压缩质量≥192kbps）。
- **配音**：干音、降噪处理、标注文本与时间戳，采样率≥48kHz。
- **其他**：工程文件（如Cubase/Pro Tools项目）、混音预设、版权授权书。

## 三、分辨率/时长规范

### 3.1 美术分辨率

- **角色贴图**：至少1024×1024（移动端）/ 2048×2048（PC端），支持POT（2的幂次）。
- **场景贴图**：至少512×512，大型场景可至4096×4096。
- **UI切图**：按目标分辨率输出，如1080p对应@1x，4K对应@2x。
- **特效序列帧**：单帧分辨率≤512×512，帧数≤30帧。

### 3.2 音效时长

- **背景音乐**：循环类≥30秒，非循环类按需（通常≤3分钟）。
- **音效**：单次触发类≤5秒，循环类≥10秒。
- **配音**：单句≤30秒，长对白需分段。

## 四、版权归属

### 4.1 知识产权条款

- 供应商需签署**知识产权转让协议**，明确交付物版权、使用权、修改权、复制权等全部归甲方（游戏公司）所有。
- 供应商保证交付物为原创，不侵犯第三方版权、商标权、肖像权等。
- 若使用第三方素材（如音效库），需提供合法授权证明，且授权范围覆盖游戏发行区域。

### 4.2 验收中的版权确认

- 验收时需附带**版权声明文件**，列明交付物清单、原创声明、授权范围。
- 对于AI辅助生成的内容，需标注并确认无版权争议。

## 五、验收审批节点

### 5.1 验收流程

1. **初验**：供应商提交交付物，项目组进行技术检查（格式、分辨率、时长等）。
2. **内容评审**：美术/音效总监进行艺术质量评审，提出修改意见。
3. **修改反馈**：供应商在约定时间内修改，重新提交。
4. **终验**：项目组确认所有问题关闭，签署验收单。
5. **入库**：资源上传至资产管理平台，标记为“已验收”。

## 七、常见误区

- **误区1**：仅检查最终文件，忽略源文件。
  - **纠正**：源文件是后续修改的基础，必须纳入验收清单。
- **误区2**：分辨率越高越好，不考虑性能。
  - **纠正**：应根据目标平台（移动/PC/主机）设定合理分辨率上限。
- **误区3**：音效时长随意，导致循环不自然。
  - **纠正**：循环类音效应有明确循环点，且时长满足最低要求。
- **误区4**：忽略版权文件，导致后续纠纷。
  - **纠正**：验收时必须附带版权授权书，并归档保存。
