# 工艺卡与 BOM 对照检索口径（示范）

## 一、概述

工艺卡与物料清单（BOM）是离散制造工厂的两大核心数据源。工艺卡定义“怎么做”，BOM 定义“用什么做”。两者必须严格对齐，否则会导致错料、漏序、返工等质量事故。本文示范如何建立统一的检索口径，确保工艺路线、物料替代、图纸版本等信息在知识库中可快速、准确匹配。

## 二、适用场景

- **新产品导入（NPI）**：工艺员编制工艺卡时，需同步核对 BOM 中的物料编码、用量及替代料。
- **工程变更（ECN）**：当 BOM 或图纸版本更新时，工艺卡必须同步修订，并记录变更历史。
- **现场排产与领料**：操作工根据工艺卡调用 BOM 物料，避免错领或漏领。
- **质量追溯**：发生异常时，通过工艺卡与 BOM 的关联字段快速定位问题批次。

## 三、操作要点

### 3.1 工艺路线与 BOM 结构对齐

- 工艺卡中的每道工序应关联 BOM 中对应的物料层级（如：总装工序对应成品级物料，焊接工序对应子件级物料）。
- 建议在工艺卡中增加“BOM 层级”字段，例如：
  - 工序 10：下料 → BOM 层级 2（板材）
  - 工序 20：焊接 → BOM 层级 3（焊接组件）

### 3.2 物料替代管理

- BOM 中允许的替代物料（如：品牌 A 电阻可用品牌 B 替代）必须在工艺卡中明确标注，并注明替代条件（如：缺料时启用，需经工艺员确认）。
- 知识库检索时，可设置“替代物料”标签，支持按原物料编码或替代物料编码双向查找。

### 3.3 图纸版本对齐

- 工艺卡中引用的图纸版本号必须与 BOM 中该物料的当前有效版本一致。
- 建议在工艺卡中增加“图纸版本”字段，并定期与 PLM 系统同步。
- 当图纸升版时，系统自动触发工艺卡修订提醒。

## 四、记录字段

工艺卡与 BOM 对照检索时，建议包含以下关键字段：

| 字段名称 | 说明 | 示例 |
|----------|------|------|
| 工艺卡编号 | 唯一标识 | PC-2024-001 |
| 产品编码 | BOM 顶层物料编码 | M-1001 |
| 工序号 | 工艺路线中的顺序号 | 10 |
| 工序名称 | 如：下料、焊接 | 焊接 |
| 物料编码 | 本工序使用的物料编码 | M-2005 |
| 物料名称 | 物料描述 | 不锈钢板 3mm |
| 用量 | 单件用量 | 2 |
| 替代物料编码 | 允许的替代物料 | M-2005A |
| 图纸版本 | 本工序引用的图纸版本 | Rev. C |
| 生效日期 | 工艺卡版本生效日期 | 2024-01-15 |

## 五、与信息系统联动

### 5.1 ERP/MES 集成

- 工艺卡与 BOM 的对照关系应存储在 MES 或工艺管理系统中，并与 ERP 的 BOM 数据实时同步。
- 当操作工在 MES 中报工某道工序时，系统自动校验当前 BOM 版本是否匹配，若不匹配则锁定报工。

### 5.2 知识库检索策略

- **关键词检索**：支持输入“产品编码+工序名称”或“物料编码+工艺卡编号”快速定位。
- **版本追溯**：记录每次变更的版本号、变更人、变更原因，支持按时间范围检索。
- **关联查询**：通过 BOM 物料编码可反向查询所有使用该物料的工艺卡及工序。

## 六、常见误区

### 6.1 工艺卡与 BOM 版本不同步

- **表现**：工艺卡引用旧版 BOM，导致现场使用已淘汰的物料。
- **对策**：建立变更联动机制，ECN 生效时自动更新相关工艺卡。

### 6.2 替代物料未在工艺卡中标注

- **表现**：缺料时操作工自行使用替代料，但工艺卡未规定参数调整，导致质量波动。
- **对策**：所有替代方案必须经工艺验证并写入工艺卡。

### 6.3 图纸版本号填写错误

- **表现**：工艺卡中图纸版本号与实物不一致，造成加工错误。
- **对策**：采用系统自动带出版本号，减少人工填写。

### 6.4 忽视层级对应关系

- **表现**：将成品级物料错误关联到零件级工序，导致领料混乱。
- **对策**：在工艺卡中明确每个工序对应的 BOM 层级，并设置校验规则。

## 七、总结

工艺卡与 BOM 的对照检索是离散制造工厂数据一致性的基石。通过统一字段定义、建立版本联动、强化系统校验，可有效减少错料、漏序等问题。知识库作为检索入口，应支持多维度查询与版本追溯，为现场操作与质量追溯提供可靠依据。
