# 安环隐患分级与上报要点（示范）

## 一、适用场景

本要点适用于离散制造工厂（机械加工、装配、焊接、涂装等）的日常安环巡检、专项检查及员工自主上报。涵盖隐患识别、分级、拍照取证、整改跟踪与复验闭环，并与巡检/上报信息系统联动。

## 二、隐患分级标准

隐患按严重程度与影响范围分为三级：

### 2.1 一级隐患（重大隐患）
- **定义**：可能导致死亡、重伤、重大财产损失（≥10万元）或严重环境事故。
- **示例**：危化品泄漏、特种设备安全附件失效、消防通道堵塞、电气线路严重老化裸露。
- **处置**：立即停止相关作业，现场设置警示隔离，30分钟内上报安环部门。

### 2.2 二级隐患（较大隐患）
- **定义**：可能导致轻伤、一般财产损失（1～10万元）或局部环境超标。
- **示例**：防护栏缺失、手持电动工具绝缘破损、化学品容器未张贴标签、通风系统故障。
- **处置**：2小时内上报，限期3天内整改。

### 2.3 三级隐患（一般隐患）
- **定义**：不会立即导致伤害，但不符合安环规范，可能积累风险。
- **示例**：地面油污未清理、安全标识褪色、劳保用品摆放不规范、临时用电线路未固定。
- **处置**：当班内上报，限期7天内整改。

## 三、拍照取证要点

拍照是隐患记录的关键，需遵循以下原则：

1. **全景+局部**：先拍整体环境（含参照物），再拍隐患细节（如裂纹、泄漏点）。
2. **清晰对焦**：避免模糊，必要时使用闪光灯或补光。
3. **包含参照物**：在隐患旁放置尺子、硬币或标准色卡，便于评估尺寸/颜色。
4. **时间戳**：确保照片元数据包含拍摄时间，或使用水印工具。
5. **多角度**：至少从两个不同角度拍摄，避免死角。
6. **记录编号**：照片文件名或备注中关联隐患编号。

## 四、上报流程与时限

### 4.1 上报路径
- **系统上报**：通过安环巡检APP或PC端系统填写隐患信息，上传照片。
- **紧急上报**：一级隐患需同步电话通知安环主管。

### 4.2 上报字段（示范）
| 字段名 | 说明 |
|--------|------|
| 隐患编号 | 系统自动生成或手动填写（如YH-2025-001） |
| 发现时间 | 精确到分钟 |
| 发现人 | 工号+姓名 |
| 所在区域 | 车间/工位/设备编号 |
| 隐患描述 | 简明扼要，包含位置、现象、可能后果 |
| 隐患等级 | 一级/二级/三级 |
| 照片附件 | 至少2张（全景+局部） |
| 临时措施 | 如已设置警示带、停机等 |

### 4.3 整改时限
- 一级隐患：立即整改，最长不超过24小时。
- 二级隐患：3个自然日内完成。
- 三级隐患：7个自然日内完成。
- 如无法按期完成，需申请延期并说明原因。

## 五、复验闭环

1. **整改完成后**：责任人提交整改报告（含整改后照片）。
2. **复验人**：由安环专员或原发现人进行现场复验。
3. **复验标准**：隐患点已消除，措施有效，无次生风险。
4. **系统状态**：复验通过后，隐患状态更新为“已闭环”；未通过则退回整改。
5. **归档**：闭环后的隐患记录保存至少3年，用于趋势分析。

## 六、与信息系统联动

工厂安环管理系统（如EHS平台）应实现以下功能：

- **自动分级**：根据隐患描述关键词或选项，系统推荐等级。
- **超时预警**：临近整改期限时，自动推送提醒给责任人及主管。
- **统计看板**：按区域、等级、部门展示隐患分布及整改率。
- **知识库关联**：相似隐患的历史案例、标准作业程序（SOP）可一键查阅。
- **移动端支持**：现场人员可用手机拍照、语音输入、定位签到。

## 七、常见误区

1. **隐患描述模糊**：如“设备不安全”应改为“XX设备防护罩缺失，有卷入风险”。
2. **照片不达标**：只拍局部无参照，或照片过暗无法辨认。
3. **等级判定过高/过低**：需对照分级标准，必要时咨询安环部门。
4. **整改后未复验**：直接关闭隐患，导致问题反弹。
5. **系统数据不完整**：漏填区域、责任人等字段，影响统计。

## 八、参考原则（示范摘要）

- **PDCA循环**：计划（分级标准）→执行（上报整改）→检查（复验）→处理（闭环归档）。
- **风险矩阵**：结合可能性与严重性评估等级。
- **海因里希法则**：每一起严重事故背后有29起轻微事故和300起未遂先兆，强调隐患上报的重要性。
