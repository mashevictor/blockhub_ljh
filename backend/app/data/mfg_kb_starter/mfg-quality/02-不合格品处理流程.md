# 不合格品（NCR）处理流程（示范）

## 1 适用场景
本流程适用于离散制造工厂中，在来料检验、过程检验、成品检验及客户反馈等环节发现的不合格品（Nonconforming Product）的处理。涵盖从发现到闭环的全过程，涉及质检、生产、工艺、仓储、采购及质量工程等部门。

## 2 核心流程

### 2.1 发现与标识
- **发现途径**：来料检验（IQC）、首件检验、巡检、完工检验、客户退货或投诉。
- **标识要求**：立即在实物上粘贴红色“不合格”标签，标签需包含：
  - 不合格品编号（NCR-YYYYMMDD-XXX）
  - 发现日期、发现人、批次号、物料编码
  - 不合格描述（缺陷类型、数量、位置）
- **记录触发**：在质检系统或纸质表单中创建《不合格品通知单》（NCR），并通知质量工程师。

### 2.2 隔离与暂停
- **物理隔离**：将不合格品移入指定“不合格品区”（红区），上锁或围栏隔离，防止误用。
- **系统锁定**：在ERP/MES中对该批次进行“冻结”或“暂停”状态，禁止后续工序流转或发货。
- **追溯标记**：记录该批次所有已投入的工单、库位及数量，便于后续追溯。

### 2.3 评审与处置决定
由跨部门评审小组（质量、工艺、生产、采购等）在24小时内完成评审，处置方式包括：
- **返工（Rework）**：通过额外工序使产品符合要求，需编制返工作业指导书。
- **返修（Repair）**：虽不能完全符合原规格，但经客户或设计部门批准后让步接收。
- **降级使用**：用于低要求场景，需明确降级标准。
- **报废（Scrap）**：无法修复或经济上不可行，按报废流程处理。
- **退货（Return to Supplier）**：来料不合格，通知供应商处理。

评审记录需包含：评审日期、参与人、处置结论、责任部门、完成期限。

### 2.4 执行与验证
- **返工/返修执行**：由生产部门按指导书操作，质检员全程监督。
- **重新检验**：完成后必须100%检验（或按AQL抽样），合格后重新标识“合格”标签，并更新批次状态。
- **报废执行**：在监督下销毁或切废，保留影像记录。
- **退货执行**：通知仓库办理退货出库，并更新供应商绩效。

### 2.5 闭环与纠正措施
- **关闭条件**：所有处置完成、重新检验合格、系统状态更新、相关文件归档。
- **根本原因分析**：使用5Why、鱼骨图等工具，确定根本原因。
- **纠正措施（CA）**：制定并实施防止再发的措施，如修改工艺参数、更新检验标准、培训员工。
- **效果验证**：跟踪后续批次，确认措施有效后关闭NCR。

## 3 记录字段与信息系统联动

### 3.1 关键记录字段
| 字段 | 说明 |
|------|------|
| NCR编号 | 唯一标识，如NCR-20250321-001 |
| 发现日期/时间 | 精确到分钟 |
| 发现人 | 工号+姓名 |
| 物料编码/批次号 | 关联ERP物料主数据 |
| 不合格数量 | 单位：件/套 |
| 缺陷描述 | 文字+照片/图纸标注 |
| 处置决定 | 返工/返修/报废/退货 |
| 责任部门 | 生产/供应商/设计等 |
| 完成日期 | 实际关闭日期 |
| 纠正措施编号 | 关联CAPA系统 |

### 3.2 与信息系统联动
- **ERP/MES**：NCR触发批次状态变更，自动锁定库存；处置后更新可用库存。
- **QMS（质量管理系统）**：自动生成NCR台账，支持趋势分析（如帕累托图）。
- **追溯系统**：通过批次号可查询该批次所有工序、检验记录及人员。
- **供应商门户**：来料NCR自动推送供应商，跟踪退货及索赔。

## 4 常见误区与注意事项

### 4.1 常见误区
- **误区一**：发现不合格后不及时隔离，导致混料。
  - 正确做法：立即贴标签并移入红区。
- **误区二**：评审走过场，未分析根本原因就关闭。
  - 正确做法：必须完成根本原因分析和纠正措施。
- **误区三**：返工后未重新检验即放行。
  - 正确做法：返工后必须100%检验。
- **误区四**：系统状态未同步，导致库存账实不符。
  - 正确做法：处置完成后立即更新系统。

### 4.2 注意事项
- 所有NCR记录保存至少3年（或按客户要求）。
- 涉及安全、法规的不合格品需立即上报管理层。
- 返工/返修方案需经工艺和质量部门会签。
- 定期统计NCR趋势，作为持续改进输入。

## 5 参考原则（示范摘要）
- **SMED**：快速换模原则可应用于返工工装准备，减少等待。
- **AQL**：重新检验时可按AQL抽样，但关键特性建议全检。
- **SPC**：利用控制图监控过程，预防不合格产生。
- **8D报告**：复杂NCR可采用8D方法系统解决。
