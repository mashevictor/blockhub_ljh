## 服务器一键验收（复制即用）

```bash
cd /root/blockhub && git pull

# ① GA 签字全套（推荐，约 3–5 分钟）
SKIP_APK=1 bash /root/blockhub/blockhub.sh signoff http://101.32.209.251

# ② 快速八项
SKIP_APK=1 bash /root/blockhub/blockhub.sh ga-checklist http://101.32.209.251

# ③ Flutter 自选能力（已修复 manifest 解析）
bash /root/blockhub/blockhub.sh flutter-build --list
bash /root/blockhub/blockhub.sh flutter-build chat_qa,approval_flow \
  --name "测试助手" --color "#2563EB" --public-id test0001

# ④ 能力全链路
bash /root/blockhub/blockhub.sh server-test http://127.0.0.1:8001

# ⑤ 单项 E2E
bash /root/blockhub/blockhub.sh e2e-prep
cd /root/blockhub/e2e
E2E_HOME_URL=http://101.32.209.251 E2E_BASE_URL=http://101.32.209.251 \
  npx playwright test tests/home-publish.spec.ts
```

> ⚠️ 勿在 `e2e/` 目录用 `bash scripts/...`（相对路径会找不到）。统一用 `bash /root/blockhub/blockhub.sh ...`。
