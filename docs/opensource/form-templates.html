字段契约（与 Runtime / compose-edit 对齐）

  • 标签含「日期 / 归还日 / 入职 / 截止…」→ type: "date" → 原生日历
  • 标签含「时间 / 时段」→ type: "datetime-local"
  • 金额 / 数量 → number；事由 / 说明 / 现象 → textarea
  • 禁止用一个「起止时间」文本框；应拆 start_at + end_at
  • 实现落点：packages/web-core/src/resolveFormSteps.ts（标签推断）、 compose_edit._intent_page_mock（生成带 type 的 fields）、 GtgtStepComposer（消费 inputType）
