# CapShip · study_coach 功能清单（DeepSeek 生成 + 工程裁剪）

> 生成时间：2026-07-20 · 源：`backend/scripts/_gen_study_coach_features.py`  
> 原则：**学习是主路径，校正进度是辅助**

## 产品目标

帮助学生跟着**真实课本目录**把本学期内容学扎实；主路径是学习，进度校正仅为低频辅助。

## 设计原则

1. 进入能力后默认落在「今日学习 / 当前课」，不落在进度校正页  
2. Soft 步进推进学习与记结果；空库=空列表；真 API  
3. 科目分化：语文朗读/字词/习作；数学例题/练习/错题；英语听读/家默/口语  
4. **不**在每行放「设为当前」；**不**把大块校正表单放主屏  

## 屏幕与主次

| 屏幕 | 角色 | 主 CTA | 说明 |
|------|------|--------|------|
| 今日学习 | P0 主路径 | 完成小步骤 / 记结果 | 默认落地：当前课下一未完成步骤 |
| 学这一课 | P0 主路径 | 逐步完成 steps | 当前单元详情 + Soft 记跟进 |
| 课本目录 | P0 主路径 | 点课开始学 | 列表展示状态，点课进入学习 |
| 日历 | P1 | 完成当日提醒 | 学期日程，辅助节奏 |
| 校正进度 | P1 辅助 | Soft 选课校正 | **折叠入口**，仅进度偏差时用 |

## 主流程

1. 说课本名 → 确认册次（目录库）→ 生成学期计划  
2. 进入「今日学习」→ 做当前课小步骤 → 可「记一次」写家默/复习/考试  
3. 目录里点下一课继续学  
4. 仅当与老师进度不符时，打开「进度与课本」折叠区校正  

## MVP 不做（本轮）

录音上传、视频讲解、自动批改试卷（需额外媒体/题库能力）。本轮用：小步骤完成 + Soft 记结果 + 目录导航。
