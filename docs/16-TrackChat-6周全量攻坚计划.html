简化但不砍

  • NL2SQL → 预置 SQL 模板 + 参数，非任意自然语言
  • 集成 Agent → 1 个 REST 只读连接器 + 同步日志
  • 114 UI → 模板映射，行业包各精选 3 场景可 Demo
  • 压测 → 10 并发对话 smoke，非 100 并发 SLA
  • 私有化 → Docker Compose 包，K8s Helm 仅骨架
  • 编排 React Flow → Admin 菜单占位 + API 预留
