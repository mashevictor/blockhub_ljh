颜色不统一的根因（你说样式 OK、只是色没统一）：
目前至少 4 套色值 在并行——shared/design-tokens.css（灰蓝商务）、 home/src/index.css 里 :root 又写死一套、 shared/themes.ts 运行时切换主题（默认白金商务金）、 .cube-theme 区块再用硬编码边框/阴影。 模块区、广场区部分样式未走 --pri 变量，而是写死 hex 或沿用旧 token。

颜色 / 主题 — 优先看这些

  • shared/design-tokens.css 色板源头 全站 --bh-* 令牌；--pri 等兼容别名
  • shared/themes.ts 4 套主题 运行时 applyTheme() 覆盖 CSS 变量；默认 monochrome-business（金+深蓝）
  • home/src/index.css 5500+ 行 首页全部样式；:root 重复定义色值；.cube-theme 从 3370 行起
  • home/src/data/iconPalette.ts 图标色 模块/行业/分类图标颜色，从 theme 调色板取色
  • home/src/context/ThemeContext.tsx 主题 Provider，挂到 main.tsx
  • home/src/components/ThemePicker.tsx 用户切换主题 UI（若页面有入口）
