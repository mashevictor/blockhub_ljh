模块选择 UI 重构方向

功能交互（点击添加、拖拽排序、数据流编辑、拨通 API）已可用；当前问题集中在信息密度、视觉层次、移动端适配、技术文案外露。以下五套方案保持现有能力不变，只改呈现与动线。

左栏长列表难扫114 个能力纵向堆叠，无搜索/筛选，找模块费眼
三栏挤压创建页 palette + canvas + inspector 在笔记本/平板上局促
选中反馈弱已添加仅 opacity 0.35，用户不确定是否成功
广场选模块弹层小picker 10px 描述字 + 小网格，不像「选能力」而像 debug 面板
说明文字过多「PostgreSQL」「>>」、三步帮助占首屏，干扰主任务

现状结构（不改逻辑）

创建页 · ModuleView

左分类列表 + palette-item 按钮，点击添加到画布
中canvas-widget 列表 + 设备 Web/App/双端切换
右摘要 + 品牌字段 + 发布

广场 · PlazaModuleFlowPanel

上ModuleReorderStrip 拖拽条 + Pipeline 流程图
中ModuleApiPanel 拨通 API
下节点详情 + ModulePicker 小网格 + 手动输入

设计原则（各方案共通）

  • 隐藏技术词：「PostgreSQL Catalog」→「能力库」；帮助折叠为「?」或首次引导
  • 选中态：勾选角标 + 震动/弹性动画 + 底部「已选 N 项」浮条
  • 搜索优先：顶部固定搜索 + 分类 chips，默认展示「常用 12 项」
  • 手机端：单栏 + 底部 Sheet 选模块，画布改为横向已选条

方案一 · 货架卡片式

像应用商店选插件：大卡片、强分类、右侧实时手机预览

推荐 · 创建页
交互预览 · 点击卡片切换选中
常用智能交互流程审批知识数据Flutter
已选 0 项下一步：发布设置 →

交互设计

浏览默认「常用」12 卡；切换分类 chips 过滤；搜索即时高亮
选择点击卡片 toggle；选中 = 描边 + 角标 ✓ + 飞入右侧手机预览
排序手机预览内长按拖拽调整模块顺序（与广场 reorder 一致）
发布底部浮条固定「已选 N 项 · 继续」；右栏 inspector 收成抽屉

优点 / 代价

  • ✓ 扫视成本最低，适合 114 项能力库
  • ✓ 选中反馈明确，预览即所得
  • △ 需重做 ModuleView 布局（2 栏：货架 + 预览）

  • △ 多一步点击；熟用户需要「专家模式」跳过向导

交互设计

添加从左栏拖入画布 / 双击快速落点
连接节点间拖线定义顺序（自动写入 flow steps）
编辑点击节点：侧栏能力说明 + API（与广场面板统一）
统一创建页与「我的应用·管理模块」共用同一画布组件
  • ✓ 与「模块数据流」叙事一致，创建→广场体验连续
  • ✓ 视觉差异化强，符合 BlockHub 品牌
  • △ 开发量最大；需处理移动端拖线难度（可降级为自动串联）

方案四 · 对话 + 推荐条

模块选择退居二线，AI 推荐为主、手动微调为辅

与描述需求一体
描述需求后 · 一键采纳推荐模块
想做请假审批 + 制度问答，给员工用手机提交
建议组合 4 个能力：
已采纳 审批流 智能问答 知识库 + 自己加

交互设计

推荐suggest-modules API 结果以 chips 呈现，点击采纳/取消
微调「+ 自己加」打开底部 Sheet（方案一货架精简版）
模块视图独立「模块组装」入口保留，但默认隐藏三栏 builder
发布已选条始终可见，可拖拽排序
  • ✓ 最符合「五分钟搭好」产品主张
  • ✓ 减少空画布焦虑
  • △ 纯手动组模块用户需多一步「+ 自己加」

方案五 · 流水线优先

强化广场编辑体验；选模块 = 在流上插节点

推荐 · 广场/我的应用
点击节点 → 底部抽屉选模块插入
在「知识库」之后插入模块

交互设计

主视觉横向流水线（输入 → 模块… → 输出），取代上下堆叠三块区域
排序直接在流水线上拖拽节点（合并 reorder strip + pipeline）
添加节点间「+」按钮 → 底部抽屉大卡片（非 10px 小字网格）
API选中节点后右侧滑出 API 面板（桌面）/ 底部半屏（移动）
  • ✓ 直接解决广场 ModulePicker 过小、信息分散问题
  • ✓ 与「拨通全部模块」心智一致
  • △ 创建页若不用流水线，需维护两套 UI（或创建页也用简化流水线）

推荐组合（保持现有交互逻辑）

  • 创建页：方案一（货架卡片）+ 方案四（描述需求后推荐 chips 预填）
  • 我的应用 / 广场编辑：方案五（流水线优先，合并 reorder + pipeline + 大抽屉选模块）
  • 第二阶段：方案三画布作为「专家模式」开关，与方案五共用节点数据
  • 通用：去掉技术文案；搜索 + 常用分类；选中动画 + 底部已选浮条

关键 UI 令牌（对齐 design-tokens.css）

  • 模块卡片：圆角 12px、阴影 --bh-shadow-sm、选中描边 --bh-info / #6366f1
  • 正文字号 15px，模块名 13–14px semibold，描述 12px --bh-muted
  • 分类 chips：高度 32px，pill 形；与首页 ViewModeSwitcher 视觉统一
  • 减少 cube 深色玻璃在表单区的使用，模块选择区改用浅色 surface 提升可读性
