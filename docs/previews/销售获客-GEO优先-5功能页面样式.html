销售获客 · GEO 落地 Visio + 5 功能样式

先讲清 GEO 营销如何落地，再对齐昨天差异化与 5 个功能页。双击本文件即可预览。

GEO 不是爬 ChatGPT。 业界定义：让生成式引擎（豆包 / DeepSeek / Kimi / ChatGPT / Perplexity 等）在回答买家问题时 检索、引用、推荐你的公开内容。 我们能落地的产品闭环是： 可引用答案素材 → 公开可抓取页 → LLM 自检 → 留资进 sales_lead(source=geo) → 按权限跟进 → 素材归因。
交互纠偏（针对你圈出的双 Tab）： 「一线 / 主管 / 市场」不是页面功能 Tab，而是登录账号的权限身份（系统下发，用户不点着切）。 顶栏只保留获客方法一条 Tab（GEO线索 / 待领取 / 跟进成交…）。 身份只在标题旁或灰条里只读展示；不同身份看到的方法与按钮不同，而不是两排都可点的 Tab。

昨天差异化（必须保留 · 装在 GEO 之后）

  • 目的/方法优先，不按漏斗硬塞获客
  • 权限身份（非 Tab）：账号决定默认首页与可执行动作；禁止做成可切换的角色 Tab
  • 真库 sales_lead + source 渠道聚合；跟进成交降为二级
  • Gtgt 单字段推进；空库 = 空列表

1. GEO 到底在优化什么

  • SEO：抢搜索结果里的「链接点击」
  • GEO：抢 AI 回答里的「被引用 / 被推荐」
  • 引擎链路：检索网页段落 → 排序权威来源 → 合成答案并引用

2. 业界公认可操作杠杆（我们只做能进系统的）

3. 明确不做（避免假能力）

  • 不定时调用 ChatGPT「偷听」别人会话
  • 不伪造「已被豆包引用 N 次」的假仪表盘
  • 不把 SEO 排名工具冒充 GEO 线索

4. 与整体销售的关系

  • GEO = 获客方法之一（市场主责）
  • 录入 / 转介绍 / 待领取… = 其它方法（F5）

主获客路径 · 对话改页试用链接（开源框架 + >> 直接触达协作小组）

不靠企微私聊。发一个链接 → 对方用 >> 对话改页随便改 → 想「确定下来」再留关键信息。改得越多，越容易成交。

产品故事（给普通人）

  • 你发：https://blockhub.club/try/xxxx
  • 对方打开就是可运行的业务页 + 右下角 CapShip >> 悬浮框
  • 协作小组同一链接（或再邀同事），各自用自然语言改菜单/表单/流程
  • 改动先落试用草稿（真库存 token 会话），不进你们正式生产库
  • 点「确定下来 / 生成我的正式应用」→ 必须留：姓名、手机、公司 → 写入销售线索

为什么这比企微私域管用

  • 好处当场可见：改完左边页面立刻变，不用加好友聊天
  • 触达的是协作小组（采购+业务+IT 一起改），不是单线销售私聊
  • 试用本身就是你们的开源对话改页框架演示 → 与 GEO「可引用/可体验」一致

你给的主路径 + 分支出口。文案：「公海」对外叫 待领取；库字段仍可用 pool。

主路径（必须入库推进）

  1. 线索池 — 所有新线索总入口（含 GEO / 录入 / 转介绍）
  2. 待领取（原公海）— 无人认领，可被领取或淘汰
  3. 分配认领 — 主管分或一线领 → 绑定负责人
  4. 初步接触 — 首次有效沟通
  5. 需求确认 — 明确痛点与预算边界
  6. 方案报价 — 方案 + 报价版本
  7. 商务谈判 — 条款 / 折扣 / 决策链
  8. 合同签订 — 合同审批通过
  9. 交付回款 — 履约 + 回款节点
  10. 续费增购 — 成功后经营

分支出口（每阶段可离开主路径）

线索池出口：淘汰
空号/广告党直接作废
待领取出口：退回
领错退回池 / 超时回收
分配认领出口：无效退回
清洗判定无效/重复
初步接触出口：培育孵化
暂无预算，进培育池
需求确认→谈判出口：可升商机或继续
商务谈判出口：丢单
合同及以后出口：赢单 / 履约异常

转化看板（一眼看全链路 + 转化率）

和「跟进成交板」不同：成交板是干活推进卡片；看板是看数——各环节存量、环比转化率、GEO/全渠道对比

权限：主管 / 市场默认可看；一线可看「我的」 数据全部来自真库聚合；空库全是 0，不画假漏斗

要不要有？——要

  • 没有看板，转化链只是流程图，老板/主管看不出卡在哪一环
  • 跟进板 = 操作面；看板 = 洞察面；两个入口都要，别揉成一个

页面区块

  • 筛选：时间范围 · 来源（全部/GEO/录入/转介绍）· 范围（我的/全组）
  • 漏斗条：阶段人数 + 箭头上写「环转化率」
  • 出口汇总：淘汰 / 待领取退回 / 无效 / 培育 / 丢单 / 赢单 数量
  • 下钻：点某一环 → 打开该阶段线索列表（进跟进板过滤）
