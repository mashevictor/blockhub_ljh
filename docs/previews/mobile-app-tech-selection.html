CapShip · Dual Runtime

怎么生成这个网站的手机版本

BlockHub / CapShip 不是把官网压成响应式页， 而是：选型 → 同一份 page_schema + build_manifest → Web Runtime 与 Flutter APK 对称交付。 本文给出技术选型拍板、生成路径与操作清单。

拍板：Flutter 3.x 同 Schema · 同 API deliver: both runtime-app + capability_* 2026-07-27
1. 结论 2. 选型对比 3. 架构 4. 怎么生成 5. 能力包对称 6. 命令速查 7. 验收 8. 相关文档

1. 一句话结论

生产手机版 = Flutter 原生 App（APK），由 Home 发布时勾选 deliver: both（或 app）触发构建队列，按已选 capability_keys 裁剪进包。员工端 Web 仍走 runtime-web； 两端读同一 Backend API 与同一 page_schema。
主路径 · 已拍板

Flutter Native APK

Android 优先；壳在 runtime-app/；能力在 packages/capability_*。

并行可用

手机浏览器 H5

同一应用的 /r/{appId} Web Runtime；适合演示 / 未装 APK 时。

不采用

React Native / 纯响应式官网

与 CapShip 裁剪矩阵、双端包契约不一致；官网 Home 本身不是交付物。

边界：「手机版」指员工/终端用户使用的 Runtime App， 不是把 home/ 营销站或管理后台压成窄屏布局。 管理端可继续用手机浏览器访问 Admin；产品交付以 Flutter APK 为准。

4. 怎么生成（操作路径）

路径 A · 产品发布（推荐）

  1. Home 选型 勾选需要的 capability_keys；选 App 壳 app_ui_id（默认 bottom_tabs）； 交付选 both 或 app。
  2. 发布 调用 POST /creation/publish。后端写入 page_schema、 build_manifest（含 flutter_pkgs），并入队 APK。
  3. 拿 Web 与下载链 返回 web_url（手机浏览器可预览）与 download_url → /r/{public_id}/download。
  4. 构建完成 Worker 跑 scripts/flutter-build-from-publish.sh， 产出 backend/uploads/apks/{public_id}.apk。
  5. 真机安装 扫码 / 下载安装；登录后读写与 Web 同一租户 API（空库=空列表）。

Publish 输入示例

{
  "capability_keys": ["device_repair", "approval_flow"],
  "web_template_id": "tabs_portal",
  "app_ui_id": "bottom_tabs",
  "deliver": "both"
}

路径 B · 本地/运维手动打 APK

# 按发布队列（与 Home 一致）
bash scripts/flutter-build-from-publish.sh <public_id>

# 自选能力打包
bash scripts/flutter-build-custom.sh device_repair,approval_flow \
  --name "门店助手" --color "#2563EB" --public-id abc12345

# 冒烟
bash scripts/smoke-apk.sh http://<host>

仅要「手机上能用」的最快路径

若暂时不打 APK：发布后打开 web_url（或 /r/{appId}）， 用手机浏览器访问 Web Runtime。这是正式契约渲染，不是假 Demo； 但系统能力（扫码、推送、独立包名）仍以 Flutter APK 为准。

5. 能力包：Web ⟂ App 怎么对称

每新增一个业务能力，必须走路径 A（见 CapShip 规范），禁止「只做 Web」却声称已有手机版。

步骤WebApp（手机版）
注册 capability_registry.py + i18n labels
包目录 packages/web-capability-{slug}/ packages/capability_{key}/
UI 文案 useTf('cap.{key}.*') bhTf('cap.{key}.*') · 同源 key
填表交互 GtgtStepComposer（web-core） GtgtStepComposer（flutter_core）
数据 apiFetch + 真 API getRuntimeAuthedDio() + 真 API
裁剪 manifest.web_pkgs manifest.flutter_pkgs + parity 矩阵
禁止：localStorage / 内存假列表冒充业务数据； 用 WebView 套官网冒充 App；只交 HTML 预览却宣称「手机版已生成」。
