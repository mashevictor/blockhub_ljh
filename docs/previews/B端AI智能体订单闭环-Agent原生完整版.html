问题 原 Visio 流程的四重误判（AI 智能体品类下更严重）

Starr Conspiracy 2024–2025 · Gartner B2B Buying Jobs · AgentScout Enterprise AI Playbook

① 线性 13 步 vs 非线性六 Jobs
原流程：公域 → 留资 → 演示 → POC → 签约，一条直线
  • 真实采购在 6 个 Buying Job 间循环跳转
  • Agent 品类多 3 条回环：POC 失败重定场景、安全与 POC 并行、ROI 被否重算
  • 失败回退是降低自主级别（全自动→人工确认→仅建议）
→ 流程图必须画回环，节点是 Agent + Job
② 千人千面 vs 千任务千 Agent
原流程：AI 识别岗位 → 首页换皮
  • 匿名访客岗位无法可靠识别
  • 6–10 人 committee 看 21–35 份不同材料
  • CFO 不逛官网，Champion 微信转 PDF
→ 同一 Deal Room URL，Orchestrator 路由不同 Specialist Agent
③ 逛官网 vs 工件建立信任
原流程：自助体验建立信任
  • Agent 信任 = 可控的自主性（audit log、降级路径）
  • 企业软件不在官网完成核心体验
  • 信任来自 POC 报告、安全问卷预填、ROI 模型
→ 每阶段 Agent 交付可转发 PDF/Excel（Artifact Panel）
④ 卡单位置写错
原流程：死在「选供应商演示」
  • 61% 死在业务 Case / 财务否 ROI
  • 44% 死在安全 / DPA 审查
  • 63% AI PoC 不转付费；~35% 自主性恐惧
→ 主战场是 ROI / Trust / Governance / Production 四个 Agent
