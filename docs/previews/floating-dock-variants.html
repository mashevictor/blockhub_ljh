悬浮输入框 · 6 种交互方案

点击下方各方案中的输入框体验：折叠可输入、聚焦/输入自动展开。
当前线上问题：单行里嵌套 textarea 边框 + 浏览器 spin 按钮，视觉乱且难用。

方案 A · 单行胶囊

推荐

折叠 = 一条圆角胶囊，输入框无边框；展开后下方出现多行区 + 生成按钮。干净、像搜索框。

方案 B · 双层卡片

结构清晰

标题固定顶栏，输入永远在第 2 行。折叠时只有两行，不会出现「标题和输入挤一行」。

方案 C · 命令栏

极客感

类似 Raycast / VS Code 命令面板。绿色 >> 前缀，输入 >> 时下方弹出模块光球。

>>

输入 >> 选模块 · Enter 生成 · Esc 收起

业务场景
设备报修 审批流程 上海话语音 知识库

方案 D · Chat Composer

熟悉

类似 ChatGPT 底部输入：左侧 >> 模块按钮，中间圆角输入框，右侧发送。展开显示标签行。

修正现版

方案 F · 极简底线

最简

无框，仅一条底边线。聚焦时右侧出现「生成」；再展开抽屉显示选项。适合极简首页。
