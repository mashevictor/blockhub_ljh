新闻

建议 B3 后端 API + 管理后台 · 每条新闻自动生成 og:image、摘要、是否进 Share 包

优点

  • 最强「全流程是 Agent」感知

  • 内容运营压力最大

折中：B 的内容结构 · 分两期上线（4 周，风险最低）

第一期先解 committee 最急缺的 Trust + 新闻 + 案例；第二期补定价 + 角色页。

第一期 · 2 周
  • /trust Trust Center 完整页
  • /news + /news/:slug（B2 Markdown）
  • 首页：Trust Strip + 新闻 3 条
  • /cases 列表 + 1 个制造长案例详情
  • 顶栏加：信任 | 新闻
  • 行业页底部：相关新闻 2 条
第二期 · 2 周
  • /pricing 定价框架 + SLA
  • /for/it /for/finance 等 4 角色页
  • 案例扩到 3 个长案例
  • Buying Job 六入口（顶栏 Agent 版）
  • 可选：B3 新闻 API 替换 Markdown
为什么推荐折中： 61% 卡 ROI、44% 卡安全——第一期 Trust + 案例直接解 IT 和 Champion；新闻建立「公司在迭代」信任；第二期再补定价和角色页，不堵第一期上线。
