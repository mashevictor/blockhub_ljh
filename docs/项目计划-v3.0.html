3. 计划中的关键数据流（勿破坏）

sequenceDiagram participant U as 用户 participant H as Home participant API as Backend participant DB as PG participant R as Runtime Note over H,R: 发布主路径（热路径无 LLM） U->>H: 选行业/模块/弹幕 H->>API: publish API->>DB: apps + page_schema + manifest API-->>H: public_id / web_url U->>R: 打开 /r/{id} R->>API: GET schema + manifest API->>DB: 正式或作者 personal_draft R->>API: 业务 CRUD API->>DB: 能力表真数据 Note over U,R: 改页路径 U->>R: Composer 改页 R->>API: POST schema/changes API->>DB: draft/pending U->>R: 刷新仍见草稿 Note over API,DB: 管理员 approve 后全员正式

任何排期任务若引入「假列表冒充业务」或「把 LLM 塞进 resolver」= 直接否决。
