方案三 · 全云端 · 推荐实施

电信星辰 TeleASR + TeleTTS
上海话实时语音 Agent 技术方案

本方案为纯云端架构：用户浏览器采集麦克风 → BlockHub 后端 WebSocket 网关编排 → 中国电信星辰 MaaS 平台完成多方言 ASR/TTS → DeepSeek 生成上海话回复文本 → 流式合成音频回传。 无需自建 GPU，上海话 TTS 口音地道度在四方案中最高。

口音优先 ★★★★★ 云端 SaaS WebSocket 全双工 60 方言 ASR 5 方言 TTS 含上海话

为何选择电信星辰（云端）

对比阿里云 CosyVoice 指令式上海话、端侧 sherpa-onnx 等方案后的结论。

核心优势

  • 上海话 TTS 原生多方言模型：TeleTTS-Stream-MultiDialect-V3.2 单模型支持上海话、粤语、四川话、河南话、东北话，评测读音准确率 99%+（相对真人）
  • 生产级验证：万号智能客服、政务热线、数字人，月调用量 4 亿+ 次
  • ASR 混说鲁棒：TeleASR-Stream-MultiDialect-V3.2 支持 60 种方言混说，电话信道/嘈杂环境优化
  • 零运维：无需 GPU 服务器、模型热更新由电信侧负责
  • 流式端到端：ASR partial → LLM 流式 → TTS 分片，首包可压至 ~1s 感知延迟

需接受的代价

  • 需单独申请天翼 AI / 星辰 MaaS AppID + AppKey，与现有阿里云账号分离
  • 按调用量计费，长时对话成本高于自建（但省去 GPU 与算法人力）
  • 需在后端实现签名鉴权 + 双 WebSocket 代理（密钥不可暴露给浏览器）
  • 多方言 TTS 文档以控制台/商务开通为准，部分参数需开通后确认

两条云端接入路径

BlockHub 生产环境推荐路径 A；路径 B 适合快速 PoC 或已有模力方舟 Token 的场景。

路径 A · 星辰 MaaS 直连 推荐
  • 控制台：天翼 AI 控制台
  • 文档：星辰 MaaS API 参考
  • 公网域名：xirang-openapi.ctyun.cn:443
  • 协议：WebSocket + teleai-cloud-auth-v1 签名鉴权
  • 延迟最低、功能最全（热词、敏感词、VAD 参数）
路径 B · 模力方舟 Serverless PoC
  • 平台：模力方舟 Gitee AI
  • Base URL：https://api.moark.com/v1
  • 模型名：TeleASR-Stream-MultiDialect-V3.2 等
  • 鉴权：Bearer Token（统一 API Key）
  • 集成快，但实时双向流式需以模型体验页协议为准

端到端延迟预算

目标：用户说完一句话后 ≤1.5s 听到 Agent 首包音频（与方案对比文档一致）。

VAD 尾点 200ms ASR final 300ms LLM 首 token 400ms TTS 首包 300ms 网络 80ms

合计约 1.28s（乐观路径）。优化手段：

  • ASR res_status=2 中间结果达到语义完整即触发 LLM，不必等 res_status=3
  • LLM 按标点/子句切块（。！？；）立即送 TTS，不等全文结束
  • 可选升级 TeleTTS-Bistream-V3.2：LLM 每出一个字即可开始合成
  • 音频上行每 200ms 发一帧（文档要求实时性，否则报 10007 错误）

云端鉴权（路径 A · MaaS）

WebSocket 握手时必须在 Header 携带签名；仅后端生成，禁止写入前端。

连接地址模板

wss://xirang-openapi.ctyun.cn:443/aipaas/voice/v1/asr/fy          # ASR 多方言
wss://xirang-openapi.ctyun.cn:443/aipaas/voice/v1/tts/supernaturalrt  # TTS（普通话接口；多方言以商务开通文档为准）

请求头

Header必填说明
Content-Type是application/json
X-APP-ID是控制台创建的 AppID
Authorization是见下方签名格式
Device-Uuid否设备 UUID，多终端统计用

Authorization 格式

teleai-cloud-auth-v1/{X-APP-ID}/{region}/{timestamp}/{expirationSeconds}/{signedHeaders}/{signature}

# 示例（上海区域 region=SH）
teleai-cloud-auth-v1/your-app-id/SH/1728892448/180000/x-app-id/a1b2c3...

# signature = HMAC-SHA256(signingKey, canonicalRequest) 十六进制小写 64 字符
# signingKey = HMAC-SHA256(AppKey, authStringPrefix)
# WebSocket 握手 HTTP Method 按文档使用 GET

完整 Java/Python 示例见 星辰 MaaS 开发指南 · 签名认证。

ASR 流式协议详解

模型：TeleASR-Stream-MultiDialect-V3.2 · API Path：/aipaas/voice/v1/asr/fy

会话状态机（rec_status）

0 — 开始识别

发送 req_id + option（采样率、标点、热词等），等待 res_status: 0 就绪。

1 — 发送语音流

循环发送 audio_stream（Base64 PCM），建议每 200ms 一帧；接收 res_status: 2 中间结果。

2 — 结束本句

发送 rec_status: 2，接收 res_status: 3/4 最终文本与 lang 方言标签。

多轮对话

保持 WS 连接，从 rec_status: 0 重新开始；或关闭连接释放并发。

开始识别请求

{
  "option": {
    "sample_rate": 16000,
    "enable_punctuation": true,
    "enable_inverse_text_normalization": true,
    "format": "pcm",
    "hotwords": ["积木仓", "应用广场", "发布"]
  },
  "req_id": "sess-abc-001",
  "rec_status": 0
}

中间结果响应（触发 LLM）

{
  "code": 10000,
  "res_status": 2,
  "data": {
    "results": [{
      "text": "帮吾查一查审批通过率",
      "lang": "zh",
      "begin_time": 1500,
      "end_time": 2800
    }]
  }
}

上海话 ASR 调优建议

  • 上传业务热词表（应用名、上海话常用词）via hotwordlistid
  • 采样率统一 16kHz / 16bit / mono，与浏览器采集一致
  • maxendsilence 调至 400–600ms，平衡句尾检测与响应速度
  • 用户普通话夹杂上海话时，混说模型自动处理，无需手动切方言

LLM 编排（DeepSeek）

复用 BlockHub 现有 llm_gateway；语音场景需约束输出为上海话并控制句长。

System Prompt 要点

你是积木仓 BlockHub 的上海话语音助手。
- 用上海话口语回复（可适当夹杂普通话专业名词）。
- 每句不超过 30 字，方便语音合成。
- 可调用模块 API：查审批、发通知、搜索知识库等。
- 用户打断时立即停止生成。

TTS 上海话合成

模型：TeleTTS-Stream-MultiDialect-V3.2 · 输入上海话文本，输出地道上海话 PCM 流。

合成请求（基于 MaaS TTS WebSocket 协议）

{
  "req_id": "tts-abc-001",
  "text": "好呃，帮侬查好了，上个月审批通过率是百分之八十五。",
  "format": "PCM",
  "sample_rate": 24000,
  "speech_rate": 1.0,
  "volume": 50
  // 多方言模型开通后增加方言参数，例如：
  // "dialect": "shanghai"  或  "voice": "shanghai_female"
  // 以控制台/商务提供的多方言接口文档为准
}

流式响应处理

{
  "code": 10000,
  "result": {
    "audio": "//6YYmNiDlSUXjZlDP8yADQAQ1E2...",  // Base64 PCM
    "audio_len": 2500,
    "is_end": false
  }
}
# is_end=true 时本句合成结束；网关立即转发给浏览器 Web Audio 播放

音频参数（推荐）

编码PCM 16bit 单声道
采样率24000 Hz（或 16000 降带宽）
语速speech_rate 0.9–1.1
单句上限500 字符（超出截断）

BlockHub 语音网关设计

新增 FastAPI WebSocket 端点，作为浏览器与电信云之间的唯一代理。

端点定义

WS  /api/v1/voice/shanghai-agent?session_id={uuid}

# 客户端 → 网关 消息类型（JSON）
{ "type": "audio", "data": "" }
{ "type": "barge_in" }           # 用户打断，停止 TTS 播放与 LLM 生成
{ "type": "config", "hotwords": [...] }

# 网关 → 客户端 消息类型
{ "type": "asr_partial", "text": "..." }
{ "type": "asr_final", "text": "...", "lang": "zh" }
{ "type": "llm_delta", "text": "..." }
{ "type": "tts_audio", "data": "", "is_end": false }
{ "type": "error", "code": "...", "message": "..." }

Python 网关骨架（核心逻辑）

# backend/app/api/v1/voice_agent.py
@router.websocket("/shanghai-agent")
async def shanghai_voice_agent(ws: WebSocket, session_id: str = "default"):
    await ws.accept()
    auth = TeleAiAuth(settings.TELEAI_APP_ID, settings.TELEAI_APP_KEY, region="SH")
    asr = TeleAsrClient(auth)   # 长连接 ASR
    tts = TeleTtsClient(auth)   # 按需建 TTS 连接

    async def pump_asr():
        async for event in asr.events():
            if event.res_status == 2:
                await ws.send_json({"type": "asr_partial", "text": event.text})
            elif event.res_status in (3, 4) and event.text:
                await ws.send_json({"type": "asr_final", "text": event.text})
                asyncio.create_task(run_llm_and_tts(event.text))

    async def run_llm_and_tts(user_text: str):
        messages = build_shanghai_messages(user_text, session_id)
        async for sentence in stream_sentences(stream_chat_deltas(messages)):
            await ws.send_json({"type": "llm_delta", "text": sentence})
            async for chunk in tts.synthesize_stream(sentence, dialect="shanghai"):
                await ws.send_json({
                    "type": "tts_audio",
                    "data": chunk.audio_b64,
                    "is_end": chunk.is_end,
                })

    await asyncio.gather(pump_asr(), receive_browser_audio(ws, asr))

部署清单

在 101.32.209.251 服务器上的一键部署流程。

开通与配置

  1. 注册 天翼 AI 开放平台，创建应用，获取 AppID / AppKey
  2. 开通「超多方言实时语音识别」+「多方言实时语音合成」能力（或 TeleTTS-Stream-MultiDialect 套餐）
  3. 确认并发配额（默认较低，客服场景需商务升配）
  4. 服务器 .env 填入密钥；勿提交到 Git

发布命令（与现网一致）

cd ~/blockhub && git pull origin main && bash scripts/server-update.sh
# 或仅 Web：bash scripts/deploy-all.sh --web-only

Nginx / 反向代理注意

  • WebSocket 需配置 proxy_http_version 1.1 + Upgrade 头
  • 语音 WS 路径：/api/v1/voice/shanghai-agent
  • 超时建议 proxy_read_timeout 3600s（长连接会话）

成本与并发

计费维度（参考）

  • ASR：按音频时长（秒）计费
  • TTS：按合成字符数或音频时长
  • LLM：按 DeepSeek token 计费（现有账单）
  • 模力方舟：Token 资源包统购（含星辰系列）

并发与限流

  • 握手失败 4002：并发超限，需商务扩容
  • 单用户会话占用 1 路 ASR WS + 按需 TTS WS
  • 网关层可加 Redis 计数，限制每租户同时会话数

风险与对策

风险影响对策
多方言 TTS 接口路径与普通话不同 合成失败 开通后向电信技术支持确认多方言 WS Path 与 dialect 参数
签名过期 / 时钟漂移 401 鉴权失败 服务器 NTP 同步；签名有效期设 180000s
非实时送音频（10007） ASR 断开 严格 200ms 帧对齐；用 AudioWorklet 定时器
LLM 输出过长 TTS 超时 / 截断 Prompt 限制句长；流式分句
用户打断（barge-in） 语音重叠 状态机切 LISTENING，cancel LLM task + 清空 TTS 队列
