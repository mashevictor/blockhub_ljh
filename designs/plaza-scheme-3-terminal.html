方案 03 / 05 · plaza --mode=terminal

>> 终端指令流

把 Newsfeed 呈现为 CLI 输出：>> 是 prompt 前缀，用户输入 plaza feed、like、@filter 等指令，Feed 卡片作为命令结果块渲染。极客/开发者向，差异化最强。

🎯 设计意图 · >> 重新定义 Newsfeed

  • >> = shell prompt，与「定义智能体符号」的编排语义一致
  • Feed 不是刷卡片，而是查询 Agent Catalog 的返回结果
  • 点赞/评论/转发可映射为子命令，降低 UI 组件复杂度

✅ 适用场景

  • 技术团队、DevOps、喜欢 Keyboard-first 的用户
  • Admin 高级模式 / 开发者广场变体
  • 与 TrackChat CLI、API 文档叙事统一
