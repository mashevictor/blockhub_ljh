>> 魔方能力导航

左侧 3×3 能力魔方（与首页 Hero 同构）筛选 Feed；面包屑用流动 >> 连接「广场 → @受众 → 能力模块 → 排序」。Newsfeed = 按能力维度浏览 Agent 发布成果。

🎯 设计意图 · >> 重新定义 Newsfeed

  • 面包屑中每个 >> 代表一次「能力跳转」，不是普通 URL 分隔符
  • 魔方中心格高亮 = 当前选中能力（问答 / 审批 / 知识库…）
  • Feed 随魔方切换过滤，强调 Catalog 114 场景的结构化浏览

✅ 适用场景

  • 能力模块多、需要按「问答/审批/看板」分类逛广场
  • 与首页魔方带形成完整闭环：创建 → 发布 → 按能力发现
  • B 端企业用户熟悉模块概念
