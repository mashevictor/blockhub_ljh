>> 三栏流动 Feed

用顶栏 >> 跑马灯 + 卡片角标 chevron，把广场 Newsfeed 定义为「智能体发布流」——每条动态 = 一次 >> 创建 + @ 受众交付。桌面三栏布局，左导航 / 中 Feed / 右 @ 标签热榜。

🎯 设计意图 · >> 重新定义 Newsfeed

  • 首页 >> = 能力编排入口；广场 Feed = 编排结果的交付展示
  • 顶栏流动条持续传递「智能体符号」品牌感，区别于普通社交 Timeline
  • 卡片右上角半透明 >> 水印：每条都是 Agent 产物

✅ 适用场景

  • 桌面端主广场 · 与当前 /plaza 方案 B 直接迭代
  • 需要侧栏「我的应用」+ @ 标签筛选的企业内网
  • 与 Hero 魔方带、发布成功卡视觉统一
