集成原则

积木仓采用「标准 API + 可选 Webhook」与现有 ERP/CRM/OA 对接，避免替换核心系统。

常见模式：只读同步主数据、线索/工单双向同步、单点登录（SSO）、消息通知回写。

已验证系统

ERP/财务：用友 U8/YonBIP、金蝶云星空（REST/中间表）· Adapter 按签约 I3。

CRM：自建 CRM Webhook + HMAC + field_map（✅ P4-I1）；纷享销客、销售易（I4）。

协同：钉钉、企业微信、飞书群机器人消息推送（✅ P4-I2）；通讯录全量仍后续。

身份：企业微信 OAuth 扫码 → JWT（🔶 P4-I2 骨架，需 WECOM_*）；Azure AD、LDAP（I4/私有化）。

工程接口（I1/I2）

入站：POST /api/v1/integrations/ingress/webhook?connector_id=…，签名头 X-BlockHub-Signature: sha256=…

同步：POST /api/v1/integrations/{id}/sync（走 Adapter，非模拟）

IM 探测：POST /api/v1/integrations/{id}/test-message

企微 SSO：GET /api/v1/auth/oauth/wecom/start → callback 签发 JWT

冒烟：bash scripts/smoke-integration-real.sh

典型对接场景

制造：CRM 新线索 → Webhook 入站 → 积木仓事件落库；报修/审批状态 → 钉钉/飞书群通知。

零售：HR 制度 PDF → 知识库 → 门店员工自然语言问答。

物流：TMS 运单状态 API → 智能体 7×24 查询与异常推送。

实施周期

标准 REST 对接：5–10 个工作日（含联调与 UAT）。

复杂 ERP 中间表：2–4 周；需客户方 DBA/集成商配合。
